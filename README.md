# CHESS:MATE

Web-MVP персонального ИИ-тьютора для шахматистов-любителей на основе материалов `CHESS_MATE.pdf` и `ИИ Шахматы.pdf`.

## Идея

CHESS:MATE помогает игрокам с рейтингом 1000–1800 понять, почему партия была проиграна: сервис принимает PGN, выделяет ключевые ошибки, объясняет их простым языком и предлагает персональные упражнения.

## Что реализовано

- Загрузка PGN партии вручную.
- Загрузка партии из `.pgn` или `.txt` файла.
- Выбор стороны игрока: белые, чёрные или автоопределение по результату.
- Локальный демо-анализ ходов без сервера.
- Генерация 3–5 вероятных ошибок.
- Визуализация позиции на доске для каждой найденной ошибки.
- Стрелки на доске, показывающие направление проблемного хода.
- Объяснения в стиле ИИ-тренера.
- Персональные упражнения по типам ошибок.
- Карта прогресса по слабым местам.

## Запуск

Откройте `index.html` в браузере или запустите локальный сервер:

```bash
python3 -m http.server 5173
```

После этого перейдите на `http://localhost:5173`.

## Ограничения MVP

Текущая версия демонстрирует продуктовую логику и интерфейс. Она не подключает Stockfish, Chess.com/Lichess API и LLM. В промышленной версии функции `analyze_game`, `explain_mistake` и `generate_exercise` должны быть заменены на связку шахматного движка и языковой модели.
